# AI crawlers and agents (user-agent tokens)

This list changes often. If web search is available, quickly check for newly announced AI user agents before the audit and mention any additions.

| User-agent token | Company | Purpose |
|------------------|---------|---------|
| GPTBot | OpenAI | Training |
| OAI-SearchBot | OpenAI | Search (ChatGPT search results) |
| ChatGPT-User | OpenAI | User-triggered fetch (when a user asks ChatGPT to open a page) |
| ClaudeBot | Anthropic | Training |
| Claude-SearchBot | Anthropic | Search |
| Claude-User | Anthropic | User-triggered fetch |
| PerplexityBot | Perplexity | Search index |
| Perplexity-User | Perplexity | User-triggered fetch |
| Google-Extended | Google | Robots token controlling use for Gemini training/grounding (not a separate crawler) |
| Applebot-Extended | Apple | Robots token controlling use for Apple AI training |
| Meta-ExternalAgent | Meta | Training / AI features |
| Amazonbot | Amazon | Crawling for Alexa / AI features |
| Bytespider | ByteDance | Training |
| CCBot | Common Crawl | Open dataset used by many AI labs for training |
| DuckAssistBot | DuckDuckGo | AI answers |
| MistralAI-User | Mistral | User-triggered fetch |
